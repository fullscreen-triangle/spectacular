# Spectacular Demos

Simplified, isolated demonstrations of the Spectacular Bayesian Evidence Network concepts.

## 🎯 Simple CLI Demo

A command-line interface that demonstrates the core concepts with full transparency:

- **Input**: Configuration file with prompt and context
- **Processing**: Step-by-step Bayesian evidence analysis
- **Output**: Complete markdown report showing every reasoning step
- **Visualization**: ASCII art and simple diagrams of the decision process

## 🚀 Quick Start

```bash
cd demos
python simple_bayesian_demo.py --config demo_config.yaml
```

## 📁 Files

- `simple_bayesian_demo.py` - Main CLI application  
- `demo_config.yaml` - Configuration file with prompts and settings
- `bayesian_network.py` - Simplified Bayesian network implementation
- `output/` - Generated markdown reports with full reasoning traces

## 🔍 What You'll See

The demo generates a complete markdown report showing:

1. **Query Analysis** - How the system interprets your question
2. **Evidence Collection** - What information is gathered
3. **Bayesian Updates** - How beliefs change with evidence
4. **Recursive Loops** - When the system needs more information
5. **External Validation** - How answers are verified
6. **Triple Validation Plots** - Visual proof of understanding
7. **Final Synthesis** - Complete reasoning chain

Every step is logged and explained in plain English.
